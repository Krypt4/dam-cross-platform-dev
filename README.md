<h1 style="text-align: center"> Syllabus </h1>

<h2> First Year </h2>

| Module | Hours | About
|---|---|---|
| Programming | 270 | OOP with Java, algorithms, data structures, unit testing, problem-solving |
| Databases | 205 | Relational design, normalization, SQL (MySQL), stored procedures, triggers, NoSQL |
| Computer Systems | 205 | OS (Windows, Linux), virtualization, networking (TCP/IP, LAN), hardware, security |
| Markup Languages & Information Systems | 110 | HTML5, CSS3, XML, JSON, data interchange formats |
| Personal Employability Itinerary I | 	100 | Career planning, CV, interview skills, workplace rights, risk prevention |
| Development Environments | 60 | IDEs, Git/GitHub, debugging, agile methods, technical documentation |
| Optional I — Excel for IT | 50 | Advanced formulas & functions, pivot tables, data analysis, VBA macros, automation, data visualization, Excel as a data management tool in professional IT contexts |
